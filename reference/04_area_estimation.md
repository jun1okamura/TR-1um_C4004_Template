# TR-1um で 4004 は入るか — 面積見積り

## 1. 方法

OpenCores/freecores `mcs-4` の Verilog RTL (`i4004`) を **Yosys 0.33** で合成
(`synth -top i4004; abc -g simple`)、得られたセル数に
**TR-1um STDLIB の実測面積**（`03_TR-1um_facts.md`）を掛けた。

## 2. 合成結果（`i4004` 階層展開後のリーフセル）

| セル種別 | 個数 |
|---|---|
| `$_DFFE_PP_` | 204 |
| `$_AND_` | 177 |
| `$_MUX_` | 147 |
| `$_OR_` | 140 |
| `$_NOT_` | 106 |
| `$_DFFE_PN_` | 11 |
| `$_SDFFE_PP1N_` | 7 |
| `$_XOR_` | 6 |
| `$_DFF_P_` | 6 |
| `$_SDFFE_PP1P_` / `$_SDFFCE_PP0P_` | 2 / 1 |
| **合計** | **807**（FF **231**、組合せ **576**） |

FF 231本の内訳（設計上）: scratchpad 16×4 = 64、PC+スタック 4×12 = 48、
ACC/キャリー、命令レジスタ、ステートカウンタ、タイミング/IO 制御 など。

## 3. 面積換算（TR-1um STDLIB）

TR-1um にはイネーブル付き FF が無いため、`DFFE` 1本 = `DFFR`(6,297.6) + `MUX2`(3,887.5) = 10,185 µm² で計上。

| 項目 | 面積 |
|---|---|
| FF 部（231本、うち225本がイネーブル付） | 約 2.31 mm² |
| 組合せ論理（576セル） | 約 1.49 mm² |
| **素セル面積 合計** | **約 3.80 mm²**（NAND2換算 **約 2,085 ゲート**） |
| セル総幅（行高62.6µm換算） | 約 60,700 µm |

## 4. 判定

利用可能コア **1,840 × 1,840 µm = 3.39 mm²** に対し:

| 配置率 | 必要面積 | 判定 |
|---|---|---|
| 50 % | 7.60 mm² | ✕ |
| 60 % | 6.33 mm² | ✕ |
| 70 % | 5.43 mm² | ✕ |
| 80 % | 4.75 mm² | ✕ |

> **結論: 「RTL → 既存 STDLIB → 自動 P&R」というストレートなフローでは入らない。**
> 2層メタルでは配置率は現実的に 50〜60 % 程度なので、**面積は約2倍オーバー**。
> ボトルネックは **DFF セル（6,297.6 µm² = INV の 3.5倍）が 231本ある**こと。

## 5. 収める方向性（優先順）

1. **レジスタファイルとスタックをカスタムアレイ化**（最も効く）
   scratchpad 64bit + PC/スタック 48bit = 112bit を DFF から
   カスタムラッチ／スタティックメモリセルアレイに置換。
   → 1.14 mm² を約 1/4 に圧縮でき、素セル面積は **約 2.94 mm²**（配置率60%で 4.90 mm²）。まだ不足。
2. **イネーブル付き FF / ラッチセルを STDLIB に追加**（DFFE, DLATCH）
   DFF+MUX2 の 10,185 µm² → DFFE 単体なら 7,000 µm² 程度、
   さらに 2相ラッチ（φ1/φ2 は 4004 が元々持っている）なら 1bit 3,000 µm² 台も狙える。
3. **フルカスタム（オリジナル トポロジの CMOS 移植）**
   実トランジスタ数 約1,800（4004.com 抽出値）。CMOS 化で 2.5〜3千 Tr 規模。
   1 µm フルカスタムのトランジスタ密度 300〜500 µm²/Tr とすると **0.8〜1.5 mm²** で収まる。
   → **面積的には最も確実**。4004.com のマスク／回路図が一次資料として使える。
4. **機能を絞る / 2チップに分ける**
   例: CPU コアのみ実装し 4001/4002 は外部 FPGA（Tiny Tapeout 版と同じ構成）。

## 6. その他の実装上の論点

- **I/O**: 信号14本という制約は 4004 の 16ピン DIP と完全一致。ただし
  D0–D3 は双方向なので **3ステート出力ドライバ＋入力バッファを自作**（STDLIB に無い）。
- **電源**: TR-1um は 5 V 系（Tox 19.5 nm）。オリジナルの −15 V とは異なるので
  レベルは全て 5 V CMOS で再定義する。
- **速度**: 目標 740〜750 kHz。1 µm CMOS の 5V ゲート遅延は数 ns オーダーなので
  タイミングは全く問題にならない（原設計より 2〜3 桁の余裕）。
  → **面積だけが唯一の制約**。
- **クロック**: φ1/φ2 の2相ノンオーバーラップを外部入力にするか内部生成するかを決める。
- **検証**: セルレベルは IRSIM（`irsim/`）でスイッチレベル検証、
  ネットリストは ngspice、LVS/DRC は KLayout（PDK 付属ランセット）。

## 7. 再現手順

```bash
git clone --depth 1 https://github.com/freecores/mcs-4.git
cd mcs-4/rtl/verilog
yosys -p "read_verilog *.v; hierarchy -check -top i4004; synth -top i4004; \
          abc -g simple; opt_clean; stat"
# 面積換算は ../../scripts/area_estimate.py を参照
```

## 8. 追記（2026-09-08）: 設計方針確定による更新

本章の見積りは **既存 STDLIB をそのまま使う前提**の最悪ケースである。
方針確定後の再見積りは `05_cell_circuits.md` §6 / `06_design_policy.md` を参照。

- クロックは **単相**（φ1/φ2 の2相は廃止）
- 3ステートは **GIO（双方向I/Oセル）でのみ使用**、内部バスは MUX 化
- レジスタファイル + PC/スタック（112 bit）は **スクラッチのカスタムアレイ**

| ステップ | 素セル面積 | 配置率60% | 判定 |
|---|---|---|---|
| 本章（既存 STDLIB） | 3.798 mm² | 6.330 mm² | ✕ |
| + カスタムレジスタアレイ | 2.900 mm² | 4.834 mm² | ✕ |
| + TG-DFFE(22T) 化 | 2.267 mm² | 3.778 mm² | △（70%でOK） |
| + 最小サイズセル化 | **1.619 mm²** | **2.699 mm²** | **○** |
